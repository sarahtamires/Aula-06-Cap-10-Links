Introdução ao MVC

O padrão MVC (Model View Controleler) é uma arquitetura de software ultilizada no desenvolvimento de aplicações para separar a lógica de negócios,a interface do usuário e o controle de dados

Componetes do MVC

  • Model (Modelo)-Representa os dados e a lógica de negócios da aplicação.
  • View (Visão)-Responsável pela interface com o usuário e a exibição de dados.
  • Controller (Controlador)-Intermedia a comunucação entre model e view
